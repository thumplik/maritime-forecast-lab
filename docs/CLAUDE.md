# docs/

- `build-plan.md` is the spec. Change it only with a dated note in `implementation-log.md` explaining why; never silently.
- `implementation-log.md` is append-only, newest entry last. Use the `/log-progress` skill.
- `coverage-audit.md` reports measured numbers only, each with the command and dataset manifest that produced it.
- Keep numbers out of docs unless a run id or command backs them.
